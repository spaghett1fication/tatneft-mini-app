# Tatнефть Mini App - Отчёт о работах

Mini App для мессенджера MAX (на первом этапе Telegram) для заполнения ежедневной сводки выполненных работ мастерами строительно-монтажного управления.

## 📋 Описание проекта

Приложение предназначено для мастеров строительно-монтажного управления Татнефть Инжиниринг. Основная задача - максимально упростить заполнение ежедневной сводки выполненных работ и практически исключить ошибки ввода.

**Целевая аудитория:** мастера 45-65 лет, которые плохо работают с техникой.

## ✨ Основные возможности

- ✅ Простая форма с крупными элементами управления
- ✅ Автодополнение для объектов (запоминает ранее введённые)
- ✅ Fuzzy search для выбора мастера (исправление опечаток)
- ✅ Справочник видов работ с автоматическим указанием единиц измерения
- ✅ Детальный учёт техники (тип + часы)
- ✅ Детальный учёт сварщиков (количество + фамилии + часы каждого)
- ✅ Учёт монтажников (только часы)
- ✅ Валидация данных перед сохранением
- ✅ Сохранение отчётов в LocalStorage
- ✅ Редактирование сохранённых отчётов
- ✅ Панель администратора для управления отчётами
- ✅ Экспорт в Excel (CSV формат с UTF-8 BOM)
- ✅ Предпросмотр отчёта в реальном времени

## 🔄 Валидация

Приложение выполняет следующие проверки перед сохранением:

1. ✅ Дата должна быть заполнена
2. ✅ Объект должен быть указан
3. ✅ Мастер должен быть выбран
4. ✅ Хотя бы один вид работ должен быть указан
5. ✅ Для каждого сварщика должны быть указаны фамилия и часы

## 💾 Хранение данных

Все данные сохраняются в LocalStorage браузера:
- `tatneft_reports` - сохранённые отчёты
- `tatneft_objects_history` - история объектов (автодополнение)
- `tatneft_masters` - история мастеров

## 📤 Экспорт

Экспорт формирует CSV файл с кодировкой UTF-8 (с BOM) со следующими колонками:
- Дата, Объект, Мастер
- Все виды работ (17 колонок)
- Доп. работа (вне списка)
- Вся техника (19 колонок)
- Сварщики: количество, ФИО (список), общие часы
- Монтажники: часы

Файл открывается в Excel без проблем с кодировкой.

## 📱 Интеграция с Telegram

Приложение использует Telegram WebApp API для:
- Получения информации о пользователе
- Тактильной обратной связи (haptic feedback)
- Адаптации к теме Telegram
- Развёртывания на полный экран

При запуске вне Telegram активируется демо-режим.
